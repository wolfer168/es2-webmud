# 李家村事件：野羊山山賊洗劫李家村（設計草稿）

狀態：**討論中，尚未製作程式。** 房間敘述與 NPC 台詞待使用者確認後才實作。
來源：使用者提供的 `war.xlsx`，加上 2026-11-24 的討論回覆。

## 一、事件總覽

- 觸發 NPC：李嘯天（`d/lee/npc/lee_xiao_tian.c`，當鋪）。
- 結束條件：所有入侵的 NPC 死亡。
- **全服同一時間只有一場事件。** 第一位觸發的人開啟後，所有玩家共用同一場。
- 事件結束後，下次重開伺服器（rb）才能再觸發（重開時事件狀態自然歸零）。
- 事件管理程式由 Claude 設計，放在李家村自己的資料夾，不動戰鬥、技能等系統程式。

## 二、流程

| 階段 | 內容 |
|---|---|
| 1. 求助 | 玩家 `ask lee about 孝敬`，李嘯天說出被勒索的事；玩家說「幫忙」後，李嘯天請玩家去村子西邊接頭。 |
| 2. 接頭 | `/d/lee/gate_w` 西邊新增房間「上山小路」，有野羊山探子。探子問話，玩家 `say 帶來了`，再 `give bandit <款項> silver`。 |
| 3. 時限 | 探子問銀兩後**滿 60 秒**沒交錢，任務失敗，探子離開，需重新來過（不算開啟事件）。 |
| 4. 信號 | 收到錢後探子放煙火，**10～20 tick** 後全村廣播，山賊入侵。 |
| 5. 入侵 | 頭目 2 個（四人隨機取兩）＋小兵 20 個，隨機散落在李家村多個房間，會走動、對村民出手。 |
| 6. 結束 | 全部入侵者死亡後，再放一次煙火信號，廣播野羊山土匪敗走、全體撤退，事件關閉。 |

### 孝敬金額（連續開啟會加價）

- 第一次 3000 兩；**連續開啟（中間沒有換人開）**每次加 1000：第二次 4000、第三次 5000……
- 換了另一個人開啟，就從 3000 重算。
- 失敗（60 秒沒交錢）不算開啟，不加價。

## 五、事件管理程式（Claude 設計）

放在 `d/lee/` 底下（例如 `d/lee/raid_d.c`），只負責：

1. 記錄狀態：閒置 → 等收錢（60 秒計時）→ 待發（10～20 tick）→ 入侵中 → 結束。
2. 記錄誰開啟、連續開啟次數與目前孝敬金額。
3. 到時間後在李家村房間隨機生出入侵者（頭目兩個、小兵 20 個），登記到名單。
4. 入侵者死亡時回報；名單歸零就收尾（煙火、敗走廣播、關閉）。
5. 入侵者移動限制：**只能在李家村房間之間走動**。

### 入侵者行為

- 移動頻率：鬼魂每 tick 約 6%（`chat_chance 9`，三句中兩句是 `random_move`）。入侵者設為**略快**，建議每 tick 約 10%。
- 對村民出手：入侵者把李家村的村民 NPC 列為敵人（見下表「村民傷亡」）。
- 對玩家：一律主動攻擊。

### 村民傷亡（看參戰人數）

使用者定案：**村民只被打昏、不下死手；參戰玩家越多，被打昏的越少。** 建議做法：

- 參戰玩家＝事件期間在李家村、曾與入侵者交手的玩家人數 N。
- 入侵者每次要攻擊村民前，用 N 決定是否放過：N 越大，放過機率越高（例如 N=0 時大部分村民都會遇害，N≥5 時村民大多安然）。
- **村民只被打昏，不會死亡**（使用者定案，2026-11-24）：入侵者對村民不下死手，村民昏倒一陣子後自己醒來。
- 公式（暫擬）：參戰玩家 N 越多，被打昏的村民越少。

## 八、台詞與敘述（待確認）

**NPC 對話一律 `say`、表情用 `emote`，每句一行不斷行。**

### 李嘯天

- 平時（`chat_msg`）：李嘯天愁眉苦臉地在當鋪裡來回踱步，嘴裡唸著：這孝敬該給還是不該給…
- `ask lee about 孝敬`：
  - 李嘯天說道：原本這是我們的家事，不敢打擾您。
  - 李嘯天說道：不過昨兒個當鋪招牌被射了一箭，上面還掛了封信。
  - 李嘯天說道：信寫得狗屁不通，畫了堆錢寫「孝敬」，還畫了顆羊頭掛把刀。
  - 李嘯天說道：一看就是野羊四傻……不，野羊四傑的手筆。
  - 李嘯天說道：不給怕出亂子，給了又怎麼跟李員外交代，又不好開口找人幫忙…
- 玩家說「幫忙」：
  - 李嘯天說道：這……就先謝過了。信裡要我到村子西邊與野羊山的好漢接頭。
  - 李嘯天說道：至於後續如何，還沒有吩咐。
  - 事件進行中有人再問：李嘯天說道：野羊山的人已經殺進村子裡了，快去幫忙！（暫擬）
  - 事件結束後有人問：李嘯天說道：多虧您出手，野羊山的人暫時是不敢再來了。（暫擬）

### 野羊山探子（上山小路）

- 鬼鬼祟祟地躲在暗處（`look` 才看得到；房間敘述不寫他）。
- 玩家到達：探子跳了出來，說道：此山是我開，此樹是我栽，若要過此路……咦？
- 探子正盯著你看，不知道打些什麼主意。
- 探子說道：看你這副德行，你應該是李掌櫃派來的吧？（已定案）
- 探子說道：說好的三千兩白銀帶來了嗎？（金額依連續開啟次數換成四千、五千……）
  - 玩家**說任何話**，或**對探子做任何表情**，都算回應，往下進行；不限定「帶來了」。
- 探子說道：還愣著幹什麼？銀兩呢？　↔　玩家 `give bandit <金額> silver`
- 收錢後：探子說道：老子收都收了，不給點回禮倒顯得小氣了。
- 探子「嘿嘿嘿……」地奸笑了幾聲。
- 煙火：砰！的一聲，一枚青綠色的煙火在空中迸射開來，化成了一顆羊頭的形狀。（原文「青綠色美麗的紅色煙火」前後矛盾，暫改為青綠色，待確認顏色）
- 10～20 tick 後，全村廣播：遠方傳來陣陣殺聲與此起彼落的哭聲，野羊山的匪子正洗劫李家村！

### 結束（Claude 草擬，待確認）

- 山頭方向又砰地升起一枚煙火，在空中散成一團殘紅，隨風飄散。
- 遠處傳來一陣雜亂的呼喝與腳步聲，野羊山的匪眾丟盔棄甲，一路往山裡奔逃而去。
- 全部入侵者此時從遊戲裡移除（撤退）。
