# 道士職業

職業代碼為 `taoist`。以下數值是升到「目標等級」所需的**累積**分數，不會在升級時扣除。

| 分數 | 升級門檻 |
| --- | --- |
| 江湖歷練 (`survive`) | `(目標等級 - 1)^2 × 100` |
| 法術修為 (`magic`) | `(目標等級 - 1)^2 × 150` |
| 咒術道行 (`spell mastery`) | 目標等級 11 起：`(目標等級 - 10)^2 × 100`；此前為 0 |
| 實戰經驗 (`combat`) | 目標等級 12 起：`(目標等級 - 11)^2 × 100`；此前為 0 |

例如升 11 級需江湖歷練 10,000、法術修為 15,000、咒術道行 100；升 12 級需江湖歷練 12,100、法術修為 18,150、咒術道行 400、實戰經驗 100。

每次升級增加最大精 `⌊機敏 / 4⌋ + random(3) - 1`、最大氣 `⌊根骨 / 4⌋ + random(3) - 1`、最大神 `⌊靈性 / 3⌋ + random(3) - 1`。屬性用含裝備、狀態加成的數值（使用者指示，2026-11-03）。三項分別擲出 −1、0 或 +1，並先以整數除法捨去屬性除法的餘數。種族升級若先提升原始屬性，當次職業增量採用提升後的值。

每次有效施法取得法術修為 `1 + random(咒文重數 + 1)`，其中 `random(N)` 產生 0 至 N−1；第一至第四重分別取得 1–2、1–3、1–4、1–5 點。咒術道行不由命中累積：基本咒術與門派咒術（天師道法火、冰、風、雷四系與茅山咒術，凡能裝在「咒術」上的門派技能都算）都計入；每一項從第 1 級開始，升到第 sk 級給 `sk × 30`，一項練到 L 級累計 `15 × L × (L + 1)`（例如 140 級累計 296,100），各項加總（使用者定案，2026-10-23）。2026-10-24 起比照法術道行：咒術類技能每升一級當場給該級的 `sk × 30`（gain 會照實顯示），不限職業，寫在技能系統 `feature/char/skill.c` 的 `spell_mastery_growth()`；不再依技能等級重算總分，所以巫師直接設定或刪除技能時不會變動咒術道行。命中後仍取得實戰經驗 `min(1 + 效果量 / 40, 20)`；無相冰命中以咒文強度基數作效果量。實戰經驗速率仍是暫定平衡值。

每次施咒取得技能點數（使用者定案，2026-10-19）：該系咒術 `(random(悟性) × random(慧根) + random(慧根)) × (random(咒文重數) + 1)`，例如三昧真火 × (random(4)+1)、大業火 × (random(3)+1)；基本咒術用智力公式換成慧根並乘咒文重數加成 `((random(慧根)+1) × (random(慧根)+1) + random(慧根)) × (random(咒文重數) + 1)`；兩者各自擲骰，不乘停頓回合。沒命中只給 1/4、至少 1 點；風符多重催咒只要有一重命中就算命中。

仍需設計道士入職、四系技能的學習途徑，以及非戰鬥施法是否應給分。現有種族職業等級上限照常生效。
