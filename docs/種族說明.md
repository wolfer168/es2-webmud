# 種族說明（help 檔案文稿）

狀態：已製作 help 檔案（2026-10-22）：`source/upstream/mudlib/docs/help/<種族>.txt`（human 含人類族，另有 avatar.txt 內容相同）、`dance.txt`；help 主題列表 `topics.txt` 新增【種族】。選種族時「? <種族名>」讀同一份檔案（`adm/daemons/logind.c`）；刑天 dance 指令的說明也改讀 `dance.txt`；人類種族檔原本 0.01% 成為人類族的判定已拿掉（只留選種族時的 1%）。
之後要改說明文字，直接改 help 檔案即可（這份文件是原始文稿）。

定案：職業上限依程式；人類族和尚 65；人類族機率 1%（製作時拿掉人類種族檔原本的 0.01%）；黑齒抗毒只是敘述；標題「巫首」；阿修羅的主動挑戰寫「與人照面時」。來源：使用者提供的人類、人類族範本與各種族敘述（2026-10-22）；
數值依目前種族檔（`daemon/race/*.c`）填入。

用途：選種族時的「? <種族名>」與遊戲裡的「help <種族名>」顯示同一份檔案（使用者定案）。

填寫規則：
- 初始屬性上限＝建立角色時各屬性可能擲到的最高值。
- 適合職業：只列等級上限高於 50 的職業，依 武者、軍人、盜賊、道士、方士、書生、和尚 的順序；數值依程式（使用者定案）。
- 主動能力不提效果數值與冷卻時間。

□ 黑齒

□ 戰舞（help dance）

刑天族擁有古老而且神秘的特殊技能戰舞，隱藏在刑天靈魂的深處，其特殊效用和進行方式就連刑天族人也難以解釋。不過，每一刑天在需要時都可以隱約回想起戰舞的進行方式。這些舞蹈就曾經幫助他們打勝過許多艱苦的戰鬥。

只有刑天能跳戰舞，跳舞時手中必須持斧，戰鬥中無法起舞。

指令格式：dance for <舞名>

‧榮光之舞（dance for glory）：提升傷害力與防禦力
‧忿怒之舞（dance for fury）：提升傷害力與攻勢等級
‧斧舞（dance for axe）：提升斧術
‧哀傷之舞（dance for sorrow）：隨舞步恢復精、氣、神其中一項，其餘兩項略為耗損，也會消耗食物與飲水
‧祭舞（dance for rite）：隨舞步恢復精、氣、神其中一項

榮光之舞、忿怒之舞、斧舞同時只能擇一，再跳一次會取代先前的舞。
哀傷之舞與祭舞會持續一段時間，一旦進入戰鬥、離開原地或放下斧頭，舞步就會中斷。
