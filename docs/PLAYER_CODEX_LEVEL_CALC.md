# 天朝圖鑑：升級所需經驗計算機（設計草稿）

狀態：已實作（2026-11-19，使用者確認畫面後製作）。放在圖鑑「計算機」分頁（也就是遊戲網頁左側「計算機」視窗），
與「夜叉吞魂」「屬性成長」並列，新增第三個「升級經驗」。

## 一、輸入與輸出（使用者修訂，2026-11-19）

- 輸入只有三項：**種族**（下拉選單）、**職業**（下拉選單）、**目標等級**。不填目前等級。
- 輸出：每一項升級經驗（實戰經驗、武術造詣、江湖歷練、法術修為…）列出「升到目標等級的累積需求」。
- 數字是「累積總量」不是每級增量：遊戲的升級門檻是整個人生累積的點數，升級不會歸零。
- 經驗取得速度（例如 ×2）只影響取得多快，不影響這些門檻，所以不調整數字。

## 二、規則來源（遊戲程式，不改）

各職業的 `daemon/class/<職業>.c` 的 `set_next_target()`：升到 L 級時，每一項經驗的門檻是
「基礎公式(L) × 種族基數 ÷ 100」，種族基數是種族檔的 `commoner_score_base`。

| 職業 | 項目與基礎公式（L ＝ 要升到的等級） |
|---|---|
| 武者 | 實戰經驗、武術造詣 (L-1)²×150；武學之道 (L-10)²×100 |
| 道士 | 江湖歷練 (L-1)²×100；法術修為 (L-1)²×150；咒術道行 (L-10)²×100；實戰經驗 (L-11)²×100 |
| 方士 | 江湖歷練、丹道修養 (L-1)²×100；法術修為 (L-6)²×100；法術道行 (L-16)²×100 |
| 軍人 | 兵刃精熟、實戰經驗 (L-1)²×200；戰場功勳 (L-30)²×100（L 超過 30 才有） |
| 書生 | 江湖歷練、實戰經驗 (L-1)²×100；文書能力 (L-1)²×50；文學造詣、聲望 (L-10)²×50 |
| 和尚 | 江湖歷練、佛學修為 (L-1)²×100；禪定修養、文書能力 (L-10)²×100；聲望 (L-30)²×100 |
| 盜賊 | 江湖歷練 (L-1)×100；實戰經驗、偷盜伎倆 (L-1)²×100；黑道聲望 (L-31)×100 |
| 平民 | 江湖歷練 (L-1)²×100（等級上限 50） |

括號小於等於 0 的項目在那一級不需要，不顯示。種族基數：人類 100、人類族 100、黑齒 120、厭火 115、焦僥 95、無腸 100、
釘靈 95、刑天 160、雨師妾 100、巫首 150、夜叉 140、阿修羅 180。

## 三、顯示的其他規則

- 該種族不能擔任這個職業（種族檔職業等級上限為 -1）：顯示「這個種族不能擔任這個職業」，不顯示數字。
- 目標等級超過該種族該職業的等級上限（例如人類武者 50）：照算，但標示「超過等級上限，無法升到這一級；以下數字僅供參考」。
- 目標等級最低 1；沒填或不合理的輸入顯示提示，不顯示結果。
- 括號小於等於 0 的項目在那一級不需要，不顯示。

## 四、製作方式

- 全部從遊戲程式讀：`tools/build_player_codex.py` 解析各 `class/*.c` 的 `set_next_target()`、種族檔的基數與等級上限、
  `data/chinese.o` 的項目中文名；遊戲規則改了重新產生圖鑑就跟著更新，解析不出來會直接報錯提醒。
- 只改圖鑑與網頁檔案，不改遊戲，不需要重開遊戲服務。

## 五、畫面範例

- 人類 武者 目標 40 級：實戰經驗 228,150、武術造詣 228,150、武學之道 90,000。
- 夜叉 道士 目標 50 級：江湖歷練 336,140、法術修為 504,210、咒術道行 224,000、實戰經驗 212,940。
- 人類 武者 目標 60 級（上限 50）：顯示超過上限的提示，仍列出 522,150、522,150、250,000。
- 夜叉 書生：顯示「這個種族不能擔任這個職業」。

## 六、實作備註

- 規則由 `tools/build_player_codex.py` 的 `level_calc_data()` 讀出，公式轉成網頁可算的算式，轉換前先檢查只含數字與運算符號。
- 已對照遊戲：用 12 個種族 × 8 個職業 × 8 個等級（2、11、12、17、31、32、45、100）共 768 組，直接呼叫各職業的
  `set_next_target()`，與計算機的 2,784 個數值逐一比對，全部相符。
- 平民的等級上限用 `feature/char/score.c` 的 `COMMONER_LEVEL_CAP`（50），不是種族檔裡的 1。
