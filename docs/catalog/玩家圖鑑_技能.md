# 玩家圖鑑：技能成長資料

玩家版天朝圖鑑（`web/codex.html`）的「技能」分頁讀這份表格，顯示每項技能練成時的等級、
精氣神與屬性的成長。規劃見 `docs/PLAYER_CODEX_PLAN.md`。

- **只寫成長結果，不寫經驗值（累積點數）的計算公式**（使用者指示，2026-10-23）。
- 「練成」欄留空時，圖鑑自動讀技能檔的學成等級（`query_entry_level()`、`art_entry`），沒有指定的是 1 級。
- 屬性欄留空、而技能在 `feature/char/skill.c` 的 `ATTR_GROWTH` 對應表裡時，圖鑑自動寫
  「每練到 5 的倍數有機會提升某屬性 1 點」。
- 「歸屬」寫專屬的門派或職業（使用者指示，2026-10-24），例如善想禪要為和尚專屬；寫門派名稱時圖鑑會連到門派卡片，
  寫職業名稱時顯示「某某專屬」。留空時依傳授的師父判斷。
- 內容依各技能檔的程式整理（2026-10-23）；技能改版時請一起更新這份表格。
