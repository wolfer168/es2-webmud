## 一、整體流程

```
有水的房間 → fish → 檢查釣竿＋魚餌 → 下竿 → 每 1 tick 判定一次 → 釣起河魚
→ 吃魚（5% 吐出河魚腹珠）→ 拿腹珠給五堂鎮珍寶商人 → 抽獎
```

## 三、fish 指令

### 3.1 前置檢查

1. 房間要有 `fishing` 旗標。
2. 身上要有**任意釣竿**：物品 id 含 `stick` 或 `rod`
   （現有 `d/swaylan/obj/fishing_stick.c`、`custom/weapon/whip/` 三支釣竿，竹釣竿的 id 是 `rod`、
   不是 `stick`，所以兩種都認）。
3. 身上要有**魚餌** `bait`（`d/swaylan/obj/bait.c`，疊加物品）。
4. 已經在釣魚中不能再下竿；戰鬥中不能釣魚。
5. 檢查不過時的提示（不提指令）：

   | 情況 | 提示 |
   |---|---|
   | 沒有釣竿 | 你身上沒有釣竿，空手怎麼釣魚？ |
   | 沒有魚餌 | 鉤上空空的，魚兒是不會理你的，總得先有點魚餌。 |
   | 不是水邊 | 這裡沒有可以垂釣的水邊。 |
   | 已在釣魚 | 你已經下了竿，耐心等著吧。 |

### 3.2 下竿

- 下竿時**消耗 1 份魚餌**（不管有沒有釣到）。
- 敘述：你把魚餌掛上鉤，手腕輕輕一抖，絲線劃出一道弧線，魚鉤「噗通」一聲沒入水中。
- 下竿後進入「垂釣中」狀態，用 `call_out` 每 1 tick 判定一次，最多 10 次。
- 垂釣中是「忙碌」狀態，不能走動；用 halt 收竿：「你收起釣竿，這回算是白忙一場。」（魚餌不退還）
- 垂釣中還沒有咬鉤的 tick，偶爾給一句氣氛敘述（浮標輕輕晃了一下、水面泛起小圈漣漪），不是每 tick 都出。

### 3.3 命中判定

「技巧」值 `s` = 玩家的捕魚技巧 `query_skill("halieutics")`
（**含釣竿、簑衣等裝備加成**——現有生鐵釣竿 +5、簑衣 +10 都已經寫在裝備上）。

第 n 個 tick（n = 1…10）：

```
n < 10：  (n - 1) × 20 + random(s) > 200   → 釣起
n = 10：  必定釣起
```

| tick | 判定式 |
|---|---|
| 1 | random(s) > 200 |
| 2 | 20 + random(s) > 200 |
| 3 | 40 + random(s) > 200 |
| … | 每多 1 tick 多 +20 |
| 9 | 160 + random(s) > 200 |
| 10 | 必定釣起 |

這個式子的特性：

- `random(s)` 的最大值是 s - 1，技巧 s ≤ 21 的人前 9 個 tick 都不可能命中，固定等第 10 個 tick。
- s 越高，越早有機會命中；每 tick 命中率 = `(s - (201 - (n-1)×20)) / s`（不為負）。

| 技巧 s | 最早可能命中 | 第 5 tick 前累積命中率 | 平均等待 |
|---|---|---|---|
| 21 以下 | 第 10 tick（必中） | 0% | 10 tick |
| 50 | 第 9 tick | 0% | 約 9.8 tick |
| 100 | 第 7 tick | 0% | 約 8.5 tick |
| 140 | 第 5 tick | 約 14% | 約 7.1 tick |
| 150 | 第 4 tick | 約 24% | 約 6.6 tick |
| 200 | 第 2 tick | 約 69% | 約 4.7 tick |
| 250 | 第 1 tick | 約 90% | 約 3.1 tick |

（程式試算結果，製作後再實測校正。）

### 3.4 技能成長與江湖歷練

- 技能：`halieutics`（捕魚技巧），新增技能檔 `daemon/skill/halieutics.c`，仿 `archaic_attainment.c`。
- **每釣起一條河魚就加技能點數**（幅度製作時依其他技能的節奏定，等越久加得越少，讓高手快釣）。
- **升級獎勵**：技能每升到第 n 級，給 **n × 30** 點江湖歷練（score of survive）。
  做法同古文造詣：以「累計應得 = 15 × 等級 × (等級 + 1)」補足差額，練過的等級也會補上。
- 累計江湖歷練：

  | 練到 | 累計江湖歷練 |
  |---|---|
  | 140 級 | 15 × 140 × 141 = **296,100** |
  | 200 級 | 15 × 200 × 201 = **603,000** |

  （140 到 200 之間再多拿 306,900。）

## 四、河魚（river fish）

- 名稱：**河魚**，id `river fish`、`fish`
- 食物：**20**（`food_stuff` 20）
- 敘述（新寫）：

  > 一尾剛從河裡釣上來的魚，銀灰色的鱗片在光下閃著水光，尾巴還在不甘心地拍打。清蒸、燒烤都好，
  > 就算生啃也填得了肚子。

- 單件物品（不疊加）、重量暫定 200、價值暫定 20。
- 釣起時的敘述（每次釣到隨機挑一則）：
  - 浮標猛地往下一沉，你手腕一翻，一尾河魚被甩出水面，在半空閃著銀光。
  - 絲線忽然繃直，你穩住竿身緩緩收線，一尾河魚拖著水花被拉上了岸。
  - 水面「嘩」地炸開，你順勢提竿，一尾河魚已經在鉤上活蹦亂跳。

### 河魚腹珠（fish pearl）

- 吃完河魚時，**5% 機會**吃出河魚腹珠（吃的當下就判定，進身上的物品欄）。
- 吃到時的敘述：你嚼著嚼著，牙齒忽然碰到一顆硬硬的東西，吐出來一看，竟是一顆圓潤的珍珠！
- 名稱：**河魚腹珠**，id `fish pearl`、`pearl`
- 重量 **10**、價值 **10000**
- 敘述（新寫）：

  > 一顆從河魚肚子裡找到的小珍珠，珠身渾圓，在手心裡泛著柔和的乳白光澤。珍寶商人都說，這種
  > 河珠雖不比海珠名貴，卻自有一股說不出的靈氣，愛珍寶的人多半肯收。

## 五、珍寶商人抽獎

地點：`/d/wutang/inn3`（醇雨樓客棧三樓）的 **珍寶商人**（`d/wutang/npc/jeweller.c`）。

### 5.1 兌換方式

`give 河魚腹珠 to jeweller`（給商人一顆腹珠 = 抽一次）。
一次只收一顆；給別的東西，商人說「這個我不收。」並退回。

**東西太重或拿不下時**：抽獎前先算，**獎品先抽出來、再試著交給玩家**。
`give` 本身是玩家給商人，商人不會拿不動。獎品是商人給玩家：身上放不下（超重或疊加物品放不進）時，
獎品**改放在地上**，商人說一句「你身上放不下，東西我替你擱在地上了。」不會消失、也不會退還腹珠。
腹珠一旦收下就算抽過一次。
**待使用者決定**：也可改成專用的 `draw` 指令。我建議沿用 give，不必新增指令。

### 5.2 商人敘述（一行不斷行，說話用 say，表情用 emote）

- 收下腹珠：`emote("接過腹珠，湊到窗邊對著光細細端詳。")`
- 抽獎前：`say("嗯，珠子成色不錯，來，讓我看看今天運氣怎麼樣。")`，停 1 tick
- 抽獎後：依獎品類別各說一句（見 5.4），並把獎品給玩家
  （東西放不下或太重，掉在地上，並提示一聲）

## 八、製作時的實際取捨（2026-11-20）

- 房間：12 間建議名單加水月瀑布，共 13 間（備選的木道、舊渡口、雪亭溪邊、溪邊小路不納入）。
- 垂釣用 busy 機制，每 heartbeat 判定一次；halt 收竿。
- 技能點數：第 n 個 tick 釣起得 (11 - n) × 10 點；升級門檻打一折（`query_threshold_percent` 10），之後可再調。
- 江湖歷練（survive）取得有全站 ×2 倍率，技能檔先減半再給，讓實拿等於 n × 30。
- 吃魚吐珠由河魚的 `stuff_ob` 處理，沒改 `eat.c`。
- 抽獎由珍寶商人的 `accept_object` 處理，沒改 `give.c`。
