## 〇、原版說明（使用者提供）

> 丹道【黃白之術】(alchemy-wealth)
> 學習條件：任務達成後習得
> 任務起始：江述仁
> 特殊能力：gold_seal／silver_seal：金銀咒並沒有本質區別，都是用以將物品轉換為金錢並直接存入錢莊。轉化 500 文以下的物品並沒有等級區別，500 文以上的物品需要技能等級大於物品價格除以 10000（文）才有效。每次使用消耗 15 點的 sen。
> 相關參考：help alchemy-wealth

本設計依使用者決定修改了原版的部分規則（金咒 90 級才領悟、金咒不限價值等），以下各章為準。

## 二、銀咒與金咒

### 2.1 咒的種類

| 咒 | 指令 | 顯示名稱 | 可轉化的物品 | 可用等級 |
|---|---|---|---|---|
| 銀咒 | `conjure silver seal on <物品>` | 銀咒 | 價值 **500 文以下** | 0 級起 |
| 金咒 | `conjure gold seal on <物品>` | 金咒 | **任何價值**（不限技能等級） | **90 級領悟後** |

| 編號 | 規則 |
|---|---|
| W-01 | 90 級以前只有銀咒；90 級領悟金咒後才能使用金咒 |
| W-02 | 金咒可用在任何價值的物品上，包括 500 文以下的物品；取消原版「技能等級 ＞ 物品價格 ÷ 10,000」的限制 |
| W-03 | 「500 文以下」指物品價值 ＜ 500 文 【實作注意】使用者原話「base_value ＜500 則僅需施用 silver_seal」，價值剛好 500 文算銀咒轉不動 |
| W-04 | 物品價值以物品本身的價值計算 【實作注意】使用者稱 base_value；實作時核對各類物品取價值的方式（`value()`、`query("value")`、成丹的 `base_value`），以一般商店計價所用的值為準 |

### 2.2 施法對象

| 編號 | 規則 |
|---|---|
| W-10 | 只能對**自己身上**的物品施法；地上的東西不能轉 |
| W-11 | 成疊的物品（例如 10 粒烏心丹、50 根松柴）**一次只轉一個**，其餘留在身上；價值以一個的價值計算 |

### 2.3 不能轉的物品（直接拒絕：不扣神、不給經驗、不加分）

| # | 不能轉的東西 |
|---|---|
| a | 錢（銅板、碎銀、黃金等貨幣） |
| b | 價值 0 的物品 |
| c | 正在穿戴、拿在手上的裝備 |
| d | **凡是能裝東西的容器**，不論裡面有沒有東西：袋子、丹爐、丹鼎、水袋等 |
| e | 人物、NPC、屍體 |
| f | 設定為不能賣、不能丟的物品（例如任務物品） |
| g | 地上的東西 |

拒絕訊息（只有施法者看得到）：「你所施用的銀咒，不可施用在這件物品上。」（用金咒時為「金咒」）

### 2.4 銀咒轉不動（直接拒絕：不扣神、不給經驗、不加分）

用銀咒對價值 500 文以上的物品施法時直接拒絕，顯示：「你所施展的銀咒，不足以轉化這把神農匕。」（「把」依物品的量詞、「神農匕」依物品名稱替換，例如「這件布衣」「這個葫蘆」）

### 2.5 消耗、成功率、失敗

| 編號 | 規則 |
|---|---|
| W-20 | 每次施法固定消耗 **15 點神**；失敗一樣扣 |
| W-21 | 神不足 15 時不能施法，不扣神、不給經驗 |
| W-22 | 成功率＝技能等級 ÷ 4 ＋ 50%，**最高 95%**（180 級達到上限） |
| W-23 | 失敗時物品**留在身上**，可以再試 |
| W-24 | 施法後**沒有忙碌時間** |
| W-25 | 尚未領悟金咒就施金咒：顯示「你尚未領悟金咒。」（不扣神、不給經驗） |

成功率範例：

| 等級 | 成功率 |
|---:|---:|
| 0 | 50% |
| 20 | 55% |
| 79 | 69.75% |
| 90 | 72.5% |
| 120 | 80% |
| 180 以上 | 95% |

【實作注意】成功率以萬分之一或小數計算，避免整數除法把 79 級的 69.75% 變成 69%。技能等級用原生等級 `query_skill("alchemy-wealth", 1)`。

### 2.6 換錢比例

存入錢莊的金額＝物品價值 × 比例（技能原生等級）：

| 技能等級 | 比例 |
|---|---:|
| 學成前（0 級） | 65% |
| 20～49 | 70% |
| 50～79 | 75% |
| 90～119 | 80% |
| 120～149 | 85% |
| 150～179 | 90% |
| 180 以上 | 95% |

| 編號 | 規則 |
|---|---|
| W-30 | 錢直接加到角色身上的錢莊存款（`bank_account`，單位：文） |
| W-31 | 【實作注意】金額計算無條件捨去到文；價值很低的物品可能換到 0 文（例如價值 1 文 × 65%），是否仍算成功由實作時回報使用者 |

## 三、技能提升

| 編號 | 規則 |
|---|---|
| U-01 | 向江述仁學，最多學到經驗值 50（見第一章） |
| U-02 | 學會後靠施展銀咒、金咒提升 |
| U-03 | 施法成功：獲得 **物品價值 ÷ 100** 點經驗【暫定】，每次最多 **技能等級 × 100** 點；**0 級（學成前）不設上限** |
| U-04 | 施法失敗：獲得 **random(靈性 ＋ 悟性)** 點經驗 |
| U-05 | 神不足、不能轉的物品、銀咒轉不動、尚未領悟金咒：不給經驗 |
| U-06 | 1～19 級不會出現：經驗累積到學成門檻後，直接學成 20 級，顯示：「你因為長期使用丹道【黃白之術】，所以你對這個法術已經逐漸熟悉。」 |
| U-07 | 79 級後不再升級，只累積經驗；經驗達到 90 級的累計值時，直接從 79 升到 90，顯示：「由於你長期使用丹道【黃白之術】，使你對丹道【黃白之術】更加的熟悉，並領悟金咒。」。**2026-11-04 修正（#31）**：原本技能系統在技能到上限時不給經驗，使 79 級卡住無法累積；現在技能檔以 `query_learn_at_cap` 表明 79 級照常累積，系統 `feature/char/skill.c` 認得這個例外 |
| U-08 | 20～79 級、90 級以後照一般技能規則升級（見 3.1） |
| U-10 | 每次施法增加**丹道修養**（`alchemy`）：成功 ＋（1 ＋ random(黃白之術等級) ÷ 2，無條件捨去），失敗固定 ＋1（與神農之術相同）；U-05 各情況不加 |
| U-12 | 系統規則：<br>A. 施法成功時，法術修為、丹道修養各 ＋ random(靈性 ÷ 6) ＋ 1（`cmds/std/conjure.c`）。U-10 的丹道修養另外照給。<br>B. 升到第 n 級時給 n × 10 法術道行（`feature/char/skill.c`）。<br>法術修為、法術道行**不另外給**（使用者原設計「每級（等級−1）×10 法術修為、超過 31 級另給（等級−30）×10 法術道行」已取消） |
| U-13 | 施法時同時累積**基本法術**（`magic`）經驗（2026-10-24，使用者指示 #12）：照茅山法術的基本法術公式，層級固定 1：（random(靈性)＋1）×（random(靈性)＋1）＋random(靈性)。施法失敗（會扣神的失敗）時取 1/3，無條件捨去，最少 1；直接拒絕、不扣神的情況不給。以 `improve_skill_exact` 給，不吃人物等級加成；只給玩家 |

【實作注意】U-10 在 0 級時避開 random(0)：0 級成功固定 ＋1。`random(n)` 為 0 到 n−1。

【實作注意】系統規則 A 目前在施法失敗時也會加分；使用者決定修正為只有真的施法成功才加分（改 `conjure.c`，所有職業的法術都適用）。實作前先查清楚各法術技能如何回報成功、失敗，向使用者說明影響範圍。

### 3.1 各等級累積經驗（系統預設門檻）

升到第 N 級所需累積經驗＝N² × 基數（`feature/char/skill.c`）。

| 等級 | 累積經驗 |
|---|---:|
| 20（學成） | 40,000 |
| 50 | 250,000 |
| 79 | 780,125 |
| 90（領悟金咒） | 1,012,500 |
| 120 | 2,160,000 |
| 180 | 6,480,000 |
| 200 | 10,000,000 |

### 3.2 練功量參考【推算】

| 階段 | 每次成功最多得到 | 說明 |
|---|---|---|
| 0 級（學成前） | 4 點 | 只能用銀咒，物品價值最高 499 文；0 級不設上限，但 499 ÷ 100 ＝ 4 |
| 20～79 級 | 4 點 | 同上；經驗上限（2,000～7,900）用不到 |
| 90 級以後 | 技能等級 × 100 | 金咒可轉任何價值；物品價值達「等級 × 10,000 文」就拿滿上限 |

以每次成功 4 點估算：學成 20 級約需成功 1 萬次；練到 79 級（約 78 萬點）約需成功 20 萬次。失敗經驗 random(靈性＋悟性)（例如靈性 17、悟性 13 平均約 15 點）比 90 級前的成功經驗多。U-03 為【暫定】，之後可再調整。

## 四、玩家訊息

自己看到的「你」依性別顯示「你／妳」。「銀咒」依實際施展換成「金咒」；「神農匕」依物品名稱替換。

| 情境 | 誰看得到 | 訊息 |
|---|---|---|
| 施法 | 自己 | 你手捏法訣，對著神農匕唸動「銀咒」。 |
| 施法 | 旁人 | $N手捏法訣，對著神農匕唸動「銀咒」。 |
| 成功 | 只有自己 | 神農匕化作一道銀光，消失無蹤。你的錢莊存款增加了七十五兩碎銀。（金咒為「金光」；金額用錢莊寫法） |
| 成功 | 旁人 | 不顯示（旁人只看得到施法過程） |
| 失敗 | 自己 | 你的法術失敗了。 |
| 神不足 | 自己 | 你的「神」不足以施展這個法術。 |
| 不能轉的物品 | 只有自己 | 你所施用的銀咒，不可施用在這件物品上。 |
| 銀咒轉不動 | 自己 | 你所施展的銀咒，不足以轉化這把神農匕。 |
| 尚未領悟金咒 | 自己 | 你尚未領悟金咒。 |
| 學成 20 級 | 自己 | 你因為長期使用丹道【黃白之術】，所以你對這個法術已經逐漸熟悉。 |
| 79 升 90 級 | 自己 | 由於你長期使用丹道【黃白之術】，使你對丹道【黃白之術】更加的熟悉，並領悟金咒。 |
| 未安裝黃白之術 | 自己 | 照系統原本的訊息 |
