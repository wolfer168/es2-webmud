## 二、描述與服用

**描述（look）**
> 醒神丹是一種提神醒腦、恢復神思的丹藥，由遠志、石菖蒲、茯神、人蔘及甘草等數種藥材煉製而成。此丹具有寧神益智之效，能使因過度耗神而疲憊的精神迅速恢復，為方士常用的丹藥之一。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 8 |
| 效果 | 食物 +5、飲水 −10、神上限回復 15～20、神 +30～35 後 −8 |
| 副作用 | 精 −5、精上限 −1 |
| 服用訊息 | $N吞下一粒醒神丹。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |
