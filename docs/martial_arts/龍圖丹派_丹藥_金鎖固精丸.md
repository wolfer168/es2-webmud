## 二、描述與服用

**描述（look）**
> 金鎖固精丸為合芡實, 龍骨, 連鬚, 潼蒺藜及牡蠣數種藥材所鍊製而成是一種方家丹藥的總稱，具澀精之療效。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 20 |
| 效果 | 食物 +5、飲水 −10、精上限回復 25～31、精 +20～34 |
| 副作用 | 神 −8 |
| 服用訊息 | $N吞下一粒金鎖固精丸。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |
