# 道士共通武功：幻劍術（virtual sword，咒術 spells）

狀態：**已實作（2026-11-24）**：`daemon/skill/virtual_sword.c`、說明檔 `docs/help/virtual_sword.txt`、
張齡的對話 `d/swaylan/npc/zhang_ling.c`；尚未在遊戲裡實測。
來源：使用者指示（2026-11-24）與施法截圖；`門派武功對照表.md` 列為道士共通、解謎取得。敘述依 `武俠敘述風格指南.md` 撰寫。
師父張齡在水嵐縣五陵客棧二樓（`d/swaylan/inn2.c`）：年輕時是劍客，後來沉迷法術，把劍術與道法融為一爐，自創幻劍術。

## 設計

| 項目 | 定案 |
|---|---|
| 種類 | 咒術，enable 在 `spells`，用 `cast` 施展 |
| 學習條件 | 道士、人物等級 5、劍術 30（使用者定案，2026-11-24）；向張齡 `say 幻劍術` 或 `ask zhang about 幻劍術`（使用者定案，2026-11-24） |
| 傷害 | 人物附加傷害（`apply/damage`）＋ 該招數字 |
| 消耗 | 神 = 總傷害的一半（至少 1） |
| 停頓 | 施咒後自身停頓 1 回合 |
| 命中 | 同天師咒術（`spell_hits`，不計對方抗性）；練武假人必定命中 |
| 練成 | 10 級（比照幽冥三箭；學成前的 0 級也能施展十面埋伏）（使用者確認，2026-11-24） |
| 招式可用等級 | 十面埋伏 0、其餘等於傷害數字（36／49／64／81／99）（使用者確認，2026-11-24） |
| 施法限制 | 不要求持劍：有持劍寫「揮劍招架」，沒持劍寫「以劍訣招架」；可對玩家、NPC、假人 |

## 張齡的對話

- `say 幻劍術` 或 `ask zhang about 幻劍術` 觸發；每人只傳一次，學過再問只會被提醒靠自己火候。
- 非道士：「這是道門的法門，與你無緣」；劍術不夠：請他先把劍練好再來（不提數字）。
- 人物等級不夠：「你的根基太淺，現在教你，只怕連劍訣都捏不穩」（不提數字）。
- 夠格：一句 emote、一句 say、一句 say、一句 emote、一句 say 介紹六招、最後 emote 講解，句與句之間停頓 1 tick；
  最後顯示「你學會了幻劍術。」並給予基本學習點數。
- 同時只跟一個人說話；說話中別人來問，回「稍等」。
