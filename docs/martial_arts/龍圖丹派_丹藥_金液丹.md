## 二、描述與服用

**描述（look）**
> 金液丹是一種方家丹藥的總稱，主要的功能是療傷，金液丹的療傷功效相當不錯，而且所需的藥材很容易買到，但是因為煉製過程比較需要技術，所以只有大城市的藥舖才買得到。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 20 |
| 效果 | 食物 +5、飲水 −10、氣上限回復 25、氣 +25 |
| 副作用 | 精 −5、精上限 −3 |
| 服用訊息 | $N吞下一粒金液丹。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |
