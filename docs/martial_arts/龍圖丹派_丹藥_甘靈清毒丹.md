## 二、描述與服用

**描述（look）**
> 甘靈清毒丹是一種清熱解毒的丹藥,由黃芩, 川貝母, 木通, 飛滑石等多種藥材鍊製而成, 為相當普遍的解藥藥物之一。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 20 |
| 效果 | 食物 +5、飲水 −10、神 +2；中毒程度 −1，降到 0 即解毒 |
| 副作用 | 無 |
| 服用訊息 | $N吞下一粒甘靈清毒丹。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |
| 其他訊息 | 自己看到（依性別你／妳）：沒中毒「你吞下這顆藥丸, 但是卻沒什麼感覺。」；解毒「你吞下這顆藥丸後, 身體的不適已經完全消除了。」；減輕「你吞下這顆藥丸後, 身體的不適感似乎稍微減輕了。」 |
