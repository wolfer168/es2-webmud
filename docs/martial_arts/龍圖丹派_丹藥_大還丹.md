## 二、描述與服用

**描述（look）**
> 大還丹是一種極神奇的仙丹, 具強大的療效可以讓服用者的內外傷在瞬間癒合, 不過煉製大還丹所需的藥材除了小還丹所需的幾樣藥材外, 還必需找尋雪蓮, 千年人蔘等數種罕見的珍貴藥材。因此, 大還丹除了燒煉困難外, 藥材之價格亦極昂貴。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 10 |
| 效果 | 食物 +7、飲水 −18、氣上限回復 70、氣 +100、HP 上限回復 10、HP +25 |
| 副作用 | 無 |
| 服用訊息 | $N吞下一粒大還丹。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |

## 六、最快時程【推算】

條件：維持最大火力（50 根），每燒掉一根立刻補一根；一次加熱＝10 次心跳≈20 秒（測試環境心跳 2 秒）。

| 項目 | 數值 |
|---|---|
| 每次加熱 | +20 |
| 熟成 | 第 95 次加熱，約 31 分 40 秒 |
| 焦化 | 第 106 次加熱 |
| 可取出的空檔 | 11 次加熱（約 3 分 40 秒） |
| 松柴總用量 | 約 144 根（720 文） |
| 一爐最多丹鼎 | 1 座（松柴 6,000＋丹鼎每座 9,500，丹爐 16,000）→ 一爐最多 1 粒 |
