# 門派武功對照表

> 使用者提供（2026-10-14），原始檔：`門派武功對照表.xlsx`。
> NPC 自動技能（`docs/CUSTOM_NPC_SKILL.md`）依這張表給門派 NPC 武功，程式在
> `source/upstream/mudlib/daemon/misc/npc_skill.c` 的門派表。

## NPC 套用規則

- NPC 寫 `set("custom_faction", 門派代碼)` 就屬於該門派（代碼見下表）。
- **拜師後**的武功從一開始就會；**LV n** 的等到人物等級 n；寫「某武功 n」的，只要學得到那套武功就視為已練滿、條件成立。
- 門派武功一律算主修（等級 × 3），它對應的基本技能也提高到主修。
- **解謎**取得的武功不會自動給門派 NPC（那是奇遇，不是師父傳的）；需要的 NPC 手動寫。
- **還沒有武功檔的**只先建立名稱與等級，不做對應；等武功檔做好，NPC 自動就會用上。
- 「共通」「道士共通」「盜賊共通」「茅山劍士」不是門派，只記錄在這裡。

## 與現有資料的衝突（使用者決定，2026-10-14）

**前置條件的算法**：NPC 只要學得到前置武功，就視為該武功已練滿。例如傲梅暗劍訣要
LV30＋寒梅心法 100，寒梅心法 LV15 就學得到，所以 NPC 到 LV30 就會傲梅暗劍訣。
