## 二、描述與服用

**描述（look）**
> 清腹丹是一種藥性峻烈的方家丹藥，由大黃、芒硝、枳實及厚朴等數種藥材煉製而成，具有通腑導滯、蕩除積穢之效。其藥力猛烈，服用後往往腹中翻攪、腸鳴不止，令人便意難抑，若非必要，實不宜輕易服用。

| 項目 | 內容 |
|---|---|
| 肚子需空出 | 20 |
| 效果 | 食物 −30、飲水 −10（清腹） |
| 副作用 | 無 |
| 服用訊息 | $N吞下一粒清腹丹。（自己看到依性別「你／妳」） |
| 吞不下 | 你的肚子已經撐得連這粒藥丸也吞不下去了。（依性別「你／妳」） |
